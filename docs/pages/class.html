クラス

PSNOVAにはハンター、レンジャー、フォース、バスターの4クラスがある。各クラスの特徴と主な装備可能武器をまとめる。取得スキルの詳細はスキルを参照。

ハンター

近距離での戦闘に真価を発揮するクラス。高いHPと防御力を持ち、単独での戦闘能力に優れる。

装備可能武器： ソード、 パルチザン、 ダブルセイバー、 ナックル

レンジャー

射撃武器による中距離からの戦闘を得意とするクラス。一撃のダメージは低いが、安全な距離から攻撃できる。

装備可能武器： アサルトライフル、 ツインマシンガン

フォース

法撃を中心とした戦闘を得意とするクラス。GPを消費してテクニックを使用することができる。

装備可能武器： ロッド、 タリス、 ウォンド

バスター

打撃・射撃・法撃全ての攻撃を高いレベルでこなすことができる補助クラス。専用武器「パイル」「ヘイロウ」を扱うことができる。

装備可能武器： パイル、 ヘイロウ
