レアドロップの仕組みと、レアアイテムを最も落としやすくする方法

敵固有ドロップでは、レア枠と通常枠が別々に判定され、効くドロップ補正も異なります。複数のドロップ補正は乗算ではなく増加分を加算して計算されます。このページでは、レア枠の仕組みとレアドロップ率を高める方法をまとめています。

敵固有ドロップは5つの枠を順番に判定する

敵固有ドロップは、次の5つの枠を上から順番に判定し、最初に成功したアイテムがその抽選の結果になります。レアアイテムは通常アイテムとは別の「レア枠」に設定されており、通常枠より先に判定されます。

  1. レア枠
  2. 通常枠1
  3. 通常枠2
  4. 通常枠3
  5. 通常枠4

「アイテムドロップ率」と「レアドロップ率」は別物

通常アイテムとレアアイテムには、別々のドロップ補正が使われています。

対象作用する補正
レア枠レアドロップ率補正
通常枠1～4アイテムドロップ率補正

そのため、通常枠に作用する「アイテムドロップ率アップ」は、同じ1回の抽選にあるレア枠の当選率を直接は上げません。ラッキーライズⅠ、テンプテーション、ギガ魚フライ定食、ギガ海鮮丼・特盛り、シャロンの「ロマンテスト」、DLCのガーネット「箱入り娘」などは通常枠を強化します。レアアイテムだけを狙う場合、テンプテーションを付けた武器を持ってもレア枠そのものの当選率は上がりません。ただし、敵1体から出せる成功アイテム数の上限を通常アイテムが先に使い切ることで、後続のレア抽選機会が減る場合があります。後述の「よくある勘違い」で詳しく説明します。

ドロップ率は乗算ではなく加算

プレイヤーが何も補正を受けていない状態のレアドロップ率を100%とします。各効果は、この100%に対する倍率として扱われます。例えば、料理による1.05倍、ブーストエネミーによる2倍といった形です。

複数の効果を重ねた場合は倍率同士をそのまま掛けるのではなく、それぞれの1倍を超えた分を100%へ加算します。

基準                         100%
2倍の効果による増加分        +100%
2倍の効果による増加分        +100%
--------------------------------
最終                         300%

2倍の効果を2つ重ねても4倍にはならず、最終的には元の3倍になります。

アイテム探知装置でレアドロップ率を上げる

アイテム探知装置では、「ダウジンガー」が通常枠、「ラッキライザー」がレア枠を強化します。施設を設置しただけでも通常側・レア側とも1.1倍になり、該当する特徴を持つクルーの人数に応じて最大2倍まで上昇します。

ラッキライザーを持つクルーは、イスタル、メイズ、カトルズ、アンリ、メルクレード、オウカ、ジャニスの7人です。アイテム探知装置を最大レベルまで発展させ、ラッキライザー持ちを5人配置するとレア側が2倍になります。

通常アイテム・レアアイテムのドロップ率を上げるアイテム探知装置については、こちらを参照してください。

よくある勘違い

ドロップアイテム増加で抽選枠が食われる

これは起こります。ただし、通常枠がレア枠そのものを奪うわけではありません。通常アイテムの当選が増えることで、敵1体から出せる成功アイテム数の上限を先に使い切り、後続のドロップ抽選が打ち切られることがあります。結果として、その後に行われるはずだったレア枠の判定機会まで減ります。

つまり「アイテムドロップ率アップはレア枠へ直接作用しない」は正しい一方で、「通常ドロップを上げても最終的なレア取得率には絶対に影響しない」は誤りです。

レアドロップ狙いなら「両持ち」も入れない方がいい場合がある

イスタルとメルクレードはダウジンガーとラッキライザーの両方を持っています。レア側を2倍にしたまま通常側も上げられるため一見得ですが、最大出現個数の上限が効く敵では、その通常ドロップ増加によって後続のレア抽選機会を減らす場合があります。

レアアイテム一点狙いでこの干渉を避けるなら、メイズ、カトルズ、アンリ、オウカ、ジャニスのラッキライザーのみ5人を配置すると、通常側を1.1倍のままにしてレア側だけを2倍にできます。レア一点狙いでは、両持ちを入れない方がよい場合があります。

グランバースト「アイテムドロップアップ」は別物

ここでいう通常ドロップ増加は、ダウジンガーやテンプテーションなど通常枠の当選率を上げる効果です。グランバースト「アイテムドロップアップ」は通常枠の倍率を上げる効果ではなく、ドロップ抽選回数を1回追加します。

捕獲するとレアドロップ率が下がる、は誤り

捕獲でも通常撃破でも、ドロップ処理へ渡される基本判定回数には同じ1.5倍補正がかかります。捕獲だけレアドロップ倍率が下がったり、基本抽選回数の1.5倍が失われたりする処理はありません。

そのため、同じ敵・同じ部位状態・同じドロップ補正を前提にすれば、捕獲したこと自体を理由にレアドロップが不利になるわけではありません。

「レアエネミー出現率アップ」と「レアドロップアップ」は別物

レアエネミー出現率アップは、通常エネミーをレア版へ置き換える追加判定に作用する効果です。すでに出現している敵のレア枠の当選率を上げる効果ではありません。レアアイテムの抽選率を上げたい場合は、レアドロップ率補正を使います。

ブーストエネミーは2倍

ブーストエネミーには2倍のドロップ補正があり、レア枠と通常枠の両方に適用されます。

v1.05でブースト発生率が設定されている敵の基礎発生率は3%です。エネミーレーダーを最大まで強化すると、この3%に8倍の補正がかかり、実出現率は24%になります。最大強化してもブーストエネミーが100%出現するわけではありません。

グランバーストのドロップ補正

効果内容
レアドロップアップレアドロップ率を2倍
アイテムドロップアップドロップ抽選を1回追加

「レアドロップアップ」は他のレア補正と同じ加算方式で、プレイヤーの基準100%に+100%が加わります。「アイテムドロップアップ」はドロップ率を上げる効果ではなく、ドロップ抽選そのものを1回増やします。

「アイテムドロップアップ」の追加抽選もレア枠から始まる

追加される1回は通常枠だけを判定するものではありません。通常のドロップ抽選と同じように、まずレア枠を判定し、外れた場合だけ通常枠1～4へ進みます。つまり「アイテムドロップアップ」は、実質的にレア枠を含む5枠の抽選をもう1回行う効果です。

「レアドロップアップ」と同時発動した場合

2つが同時に発動している場合、通常の抽選でも追加された抽選でも、最初にレアドロップ率アップ後のレア枠を判定します。そのため「アイテムドロップアップ」を併用してもレアドロップ率が下がることはなく、追加抽選まで実行されればレアを引ける機会が1回増えます。

通常の抽選
  レア枠（レアドロップアップ適用）
  → 外れたら通常枠1～4

追加された抽選
  レア枠（レアドロップアップ適用）
  → 外れたら通常枠1～4

反対に、レアドロップ率を上げると1回の抽選の中ではレア枠で先に成功しやすくなるため、通常枠まで到達する割合は下がります。ただし「アイテムドロップアップ」は抽選回数自体を増やすため、最終的な通常アイテムの入手数が必ず減るとは限りません。

また、ドロップには1体の敵から出せる成功アイテム数の上限があります。先にその上限へ達した場合は後続の追加抽選が行われないため、「アイテムドロップアップ」で必ずレア判定が1回増えるとは限りません。

バースト加速装置で狙った効果を出しやすくする

バースト加速装置へ「BURST:レアドロップ」持ちを配属すると、グランバーストで「レアドロップアップ」が選ばれる重みを増やせます。v1.05では所持者が4人のため、4人全員を配属し、他のBURST特徴を入れない場合、まだ何も効果が発動していない初回抽選で「レアドロップアップ」が選ばれる確率は4/7 = 約57.14%です。

「BURST:アイテム」は基礎候補として最初から重み1を持つため、所持者4人を全員配置すると「アイテムドロップアップ」の初回確率は5/7 = 約71.43%になります。詳しい重みの仕組みはバースト加速装置を参照してください。

抽選回数と最大出現個数

レアドロップの最終的な入手率は、レア枠の倍率だけでは決まりません。敵ごとに「基本判定回数」と「最大出現個数」が設定されており、同じレア倍率でも抽選回数が多い敵ほどレア枠を判定する機会が増えます。

通常撃破でも捕獲でも、基本判定回数には同じ1.5倍補正がかかります。グランバースト「アイテムドロップアップ」が発動していれば、そこへさらに1回が加わります。

本体側の抽選回数
  = 基本判定回数 × 1.5
  + グランバースト「アイテムドロップアップ」の追加1回
  + その他の追加抽選補正

また、本体のドロップ行とは別に、現在の部位状態と一致する部位別ドロップ行がある場合は、その行も1回ずつ判定されます。本体と部位の抽選は両方行われます。

ただし、本体・部位を合わせた成功アイテム数には敵ごとの上限があります。上限へ達すると残りの抽選は打ち切られます。このため、通常アイテムの当選率を上げすぎると、後続のレア抽選機会を減らす場合があります。

敵固有枠の後に地域・共通ドロップがある

1回の抽選で敵固有のレア枠・通常枠1～4がすべて外れた場合だけ、地域ドロップ、続いて共通ドロップの判定へ進みます。

敵固有レア枠
  → 通常枠1～4
  → 全部外れ
  → 地域ドロップ
  → 共通ドロップ

アイテム探知装置などのレア・通常ドロップ倍率は、地域・共通ドロップの確率そのものには直接かかりません。敵固有枠が当たりやすくなるほど地域・共通ドロップまで到達する割合は下がります。

解析上確認されている、ゲーム上の名称が未確定の追加抽選補正

このほか、ドロップ処理には現在までに生成された出力数を参照して追加のドロップ抽選回数を加える内部補正が存在します。追加抽選が実際にドロップ回数へ加算されること自体は確認できています。

ただし、この補正をゲーム上のどの状態・人数・表示名と対応させるべきかは完全には確定していません。そのため、現時点では「パーティ人数が増えると必ず何回増える」といった攻略情報としては断定しません。

例えば、補正前のレア枠のドロップ率が1%なら、通常敵の最大構成では3.10%、ブーストエネミーの最大構成では4.10%になります。

ここで示している3.1倍・4.1倍は1回のレア枠判定へかかる倍率です。敵1体あたりの最終取得率は、基本判定回数、部位別抽選、グランバーストの追加抽選、最大出現個数などによって変わります。

グランバースト「アイテムドロップアップ」が発生した場合は、このレア倍率とは別にドロップ抽選が1回追加されます。
