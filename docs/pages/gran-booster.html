グランブースター

グランブースターは、クエスト終了時に獲得するグランエナジーを増やし、GP消費量を軽減する拠点施設です。施設レベルそのものが補正率を直接上げるのではなく、レベルが上がるほど配属できるクルーが増えます。特徴「グラン予報士」「上級グラン予報士」を配属することで効果が段階的に強くなります。

施設レベルと配属人数

Lv1～5で配属可能人数が1～5人へ増えます。施設を設置しただけでも獲得グランエナジーは5%増加しますが、GP消費量は軽減されません。

Lv 開発費 配属可能人数 上級のみ配属時の最大効果
15001人獲得グラン +15% / GP消費 -2%
21,0002人獲得グラン +25% / GP消費 -4%
32,5003人獲得グラン +35% / GP消費 -6%
45,0004人獲得グラン +45% / GP消費 -8%
510,0005人獲得グラン +55% / GP消費 -10%

グラン予報士の効果

効果の段階を分かりやすく表すため、「グラン予報士」を1、「上級グラン予報士」を2と仮置きすると、配属中の合計に応じて効果が変化し、合計10相当で最大になります。通常と上級を混在させた場合も、この仮の換算値の合計で考えられます。

上級グラン予報士+2獲得グラン +10% / GP消費 -2%

最大効果にするには

Lv5では5人配属できるため、「上級グラン予報士」を5人配属すると、仮の換算値では10相当になります。このとき獲得グランエナジーは55%増加し、GP消費量は10%軽減されます。上級グラン予報士の所持者は6人いるため、最大構成は実際に組めます。
