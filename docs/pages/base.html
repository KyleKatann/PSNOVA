拠点

拠点ではショップや各種施設を設置し、施設効果やクルー配置による支援を受けられる。ACT Iではフィルディアのプロミスオーダーで基本施設Lv.2まで、ACT IIでは拠点編集が解放され、基本施設Lv.3までと一部の非必須施設を設置できる。各施設のサイズ、コスト、価格、効果と、インテリア・床の配置データをまとめて確認できる。

ショップや施設にはコールドスリープから目覚めさせたキャラクターを配置できる。緑アイコンの特徴を持ったキャラクターを配置すると性能が向上する。

拠点施設の解放条件

  • Lv.4: メインストーリークリア直後に解放。
  • Lv.5: SH解放までに出現する全クエストのクリアで解放。難易度・クリアランクは問わず、追加クエストは除く。

ショップ

ショップの種類は通常のものに加え、B・O・Wの計4種類。各施設の効果は重複せず、一番レベルの高いものが優先される。例えば武器ショップLv.3とLv.4を配置した場合、発生するのは攻撃力アップ+10%のみ。
