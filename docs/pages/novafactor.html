ノヴァファクター集め

ノヴァファクターはLv201以上の大型エネミーからドロップする。ノヴァ系★15装備で使う希少素材で、フィルディアのオーダー「ヘル・デート」Sクリアでも1個入手できる。数を集める場合はXHの大型エネミーを周回する。

必要装備

火力装備

周回時間を短くできる装備を用意する。

  • 無謀の型
  • ハイパーバースト
  • 使用武器に合った攻撃力上昇

無謀の型はダメージが大きく上がる代わりに最大HPが20%になる。安定しない場合は外してよい。

ドロップ用装備

テンプテーションを付けられるなら付けておく。火力が落ちる場合は普段は火力武器を使い、撃破前にテンプテーション付き武器へ持ち替える。周回時間が大きく伸びる構成は避ける。

おすすめクエスト

1. 超：デス・デート XH

本命。1周でLv201以上の大型エネミーを複数倒せるため、問題なく回れるなら単体クエストを繰り返すより対象数を稼ぎやすい。

出現順：

  • デェフキュオネ
  • グラヴディオン
  • ノイヴァトアス
  • ヴァリゴルドス
  • ヴィヴリュード
  • アルテイオス

部位破壊は周回を遅らせない範囲で行う。

デェフキュオネ

  • グランジェネレーター
  • 触手
  • 大弱点

グラヴディオン

  • 足の弱点4か所
  • 胴体の弱点2か所
  • 大弱点

ノイヴァトアス

  • ジェネレーター
  • レーザー
  • ジェネレーター
  • レーザー

ヴァリゴルドス

  • ツノ
  • ジェネレーター
  • 口
  • 弱点化した口

ヴィヴリュード

  • グランジェネレーター
  • リボルバー
  • 胴体弱点

アルテイオス

  • 尻尾の付け根
  • 弱点
  • 大弱点

1ダウンで処理できない部位まで無理に壊す必要はない。

2. 超：城壁のヴィヴリュード XH

デス・デートXHが重い場合はこちら。ヴィヴリュードとノイヴァトアスを狙える。

  • ヴィヴリュード
  • ノイヴァトアス

ノイヴァトアスまで倒してリタイアを繰り返す周回も使える。デス・デートを最後まで回すより短時間で周回できる場合はこちら。

3. 難：★ラスト・デート XH

デス・デートと同じく、1周で複数の大型エネミーを狙える。デス・デートより短時間で回れる場合はこちらも候補。

出現順：

  • デェフキュオネ
  • グラヴディオン
  • マグネトアス
  • ディゴルドス
  • ヴィヴリュード
  • アルテイオス
