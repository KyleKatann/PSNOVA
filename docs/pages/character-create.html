キャラクタークリエイト

主人公は3種族から選び、外見を細かく調整して作成する。開始時のクラスはハンター、レンジャー、フォースから選択できる。種族と性別は後から変更できないため、ゲーム開始前に決めておく必要がある。

最初に決める項目

種族
ヒューマン、ニューマン、キャストの3種類。種族によって能力傾向と外見上の特徴が異なる。
性別
男性または女性を選択する。種族と性別は一度決定すると変更できない。
初期クラス
ハンター、レンジャー、フォースから選択する。バスターはゲーム開始時には選択できず、進行後に利用可能になる。

外見の調整

キャラクタークリエイトでは、プリセットを選ぶだけでなく各部を細かく調整できる。

  • 身長や体の肉付きなど、全身の体型を調整できる。
  • 目は形、大きさ、角度、瞳の色などを調整できる。
  • 顔の各部や体型を組み合わせて、主人公の外見を作成できる。
  • 女性キャラクターはバストの大きさ、高さ、向きも調整できる。
  • 衣装のカラーも設定できる。

ヘアスタイル、コスチューム、キャスト用パーツ、アクセサリーの一覧はヘアスタイル・コスチューム・アクセサリーを参照。

種族の特徴

種族特徴
ヒューマン能力のバランスがよく、さまざまなクラスへ適応しやすい。
ニューマンフォトンの扱いに長ける一方、基本的な身体能力は低め。
キャスト機械の身体を持ち、近接・射撃戦に強い一方、フォトンの扱いは不得意。

初期クラス

クラス得意分野
ハンター高いHPと防御力を生かした近距離戦闘。
レンジャー射撃武器を使った中距離戦闘。
フォーステクニックを中心とした遠距離・法撃戦闘。

各種族の詳細は種族、各クラスの性能はクラスを参照。
