小ネタ

PSNOVAの世界観や演出、NPCの台詞、ゲーム中に見られる細かな要素をまとめる。

ユノの宝石に書かれている文字

「ユノの宝石」上部の文字はオラクル文字。解読すると「test test test 11」となり、特別な隠しメッセージではない。ルティナが入手直後に持つシーンでは宝石自体を逆さまに持っているため、文字も逆さまになっている。青い宝石部分の発光エフェクトにも文字のような模様が見えるが、こちらはオラクル文字ではない。

NPCとの会話

コールドスリープ組を含むNPCの会話はストーリー進行に応じて細かく変化する。PSO2クルーやパスワード入力クルーなどのコラボキャラクターでも台詞変化が確認されている一方、一部NPCは共通台詞のままの場合がある。
